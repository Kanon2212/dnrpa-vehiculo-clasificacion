# Artefactos del modelo

Por defecto, este repositorio no distribuye modelos serializados. El modelo entrenado puede generarse al ejecutar el notebook, pero su publicación es independiente de los resultados y del código fuente.

Si se incorpora un archivo `.joblib` o `.pkl`, documenta las versiones de Python y bibliotecas, el esquema y orden de las variables de entrada, el orden de las clases, la clase positiva y el umbral asociado. Incluye instrucciones de carga y métricas de evaluación.

No incluyas datos personales, registros individuales ni datos de entrenamiento dentro del artefacto.
